# Portfolio
Personal portfolio site I made in a weekend for myself. Uses Three.js for 3D graphics cuz thats the meta
![Preview](images/preview.png)

## How?
I used Vite.Js and the React.JS framework with Javascript along with Three.js and no css library.

## Why?
I needed a portfolio site. I have many projects, and yet I never had a clean way to showcase them other than my messy GitHub and LinkedIn.

## Run It
Run these commands.
`npm install`
`npm run dev`
